# Mini Bill Generator

simple python based bill generator where the user can add items to the cart, calculate item wise total, generate gst(5%) , and display the bill using pandas.

# Features

- Multiple items can be added to the cart

- Name, price, and quantity of the item can be entered
- The total price of the item can be calculated automatically
- The items in the cart can be displayed using pandas
- Subtotal can be calculated
- Gst can be calculated (5%)
- The final bill can be displayed
- Can handle invalid entries of numbers
- Menu driven

# Technologies Used

Python , Pandas.
# How It Works
1. Items are added to the cart
2. The name, price and quantity of the items are entered

3. The price of the items are calculated automatically
4. All the items are stored in a list of dictionaries
5. Pandas is used to display the items in the cart
6. Subtotal is calculated
7. Gst of 5% is calculated
8. Final bill is displayed
# Concepts Practiced
functions, lists, dictionaries, loops, conditional statements, user input, exception handling, calculations, pandas, dataframes, data aggregation.
# Pandas Usage
Pandas is used to store the data in the form of a dataframe, display the items in the cart in a tabular manner and calculate the subtotal using the sum() function.
# How To Run
